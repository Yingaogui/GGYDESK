GGYDESK 1.9.6 交付说明
本次修订
在 WorkBuddy 1.9.5 的独立副本上修订，保留其授权版本名称和文件审计侧栏调整，原始项目、1.9.5 以及已提交的 1.7.3 软著材料均未修改。
- 修复授权迁移：升级先备份授权、试用和时钟状态，再运行旧卸载程序，完成后恢复；应对 1.9.5 卸载逻辑会删除状态的问题。升级中断的备份保留以便重试。新版本升级卸载路径不执行普通卸载清理。
- 普通卸载仅清除本产品付费授权，不重置 7 天试用历史；不可信卸载标记不能删除授权或重启试用。保留已有公钥、应用身份和用户数据路径。
- 修复 SQLite 无密码连接被错误拦截、连接标题显示 undefined 的问题。
- 补充缺失的英文回退文本，更新首页与使用说明、替换七幅实际产品操作图。长篇手册仍以中文为主；没有声称十种语言全部完整翻译。
- 补充安装升级宏、授权篡改样本、文件服务、代理及实际界面测试，完整源码和构建脚本随包保留。

37 组、591 项自动化检查通过，0 组失败；1 组旧 Electron 33 数据迁移因缺少旧运行环境未执行。154 个 JS/CJS 文件语法检查通过。构建后的程序启动通过；136 个业务源码文件与包内一致，127 个完整性文件核验通过。
功能报告包含 27 个功能配置/验证条目、119 个最新界面断言、120 幅 PNG。HTML 的全部 146 个图片引用加载成功，搜索已验证。部分源码测试页面的版本值取自测试宿主 Electron（例如 45.0.0），并非交付软件版本；交付安装包与业务源码版本为 1.9.6。截图未修图伪造测试结果。
测试使用隔离目录和本机协议对端，包括真实 SSH 跳板、SFTP、转发、HTTP/FTP/SFTP 文件服务、SQLite、HTTP/SOCKS5 代理、有限 HTTP/HTTPS/TCP/UDP 业务流量、IPv4/IPv6 回环探测、Windows 进程与事件日志、文件监测和 NSIS 生产宏的临时目录安装迁移。未对个人安装、授权、远程业务服务器或物理串口执行测试操作。
仍需实机验收
- 自研 GGYNet 驱动尚未签名和加载验证；无 IP 网卡二层发包、PCAP 原始回放仍按约定搁置。未安装 Npcap，未改系统驱动签名策略。
- IPv6 解析/过滤及兼容入口已测试，管理员真实网卡 IPv6 采集尚未验收。
- RDP 仅本地窗口/控件停靠验证，未登录真实远端；串口仅枚举、无效端口和模拟通信；MySQL、SQL Server、Oracle、PostgreSQL 未接生产服务器验证。
- Dump 使用合成样本，提供基础停止代码/异常模块线索，不能代替完整符号和调用栈诊断。
- 安装迁移使用实际 NSIS 宏但重定向到临时目录；未在你的日常安装上执行覆盖安装。
- 安装程序无商业代码签名（NotSigned）。离线授权、完整性和篡改检查提高破解成本，无法保证绝对不可破解，尤其面对管理员替换运行时或删除所有离线状态。
安装与升级
先从托盘彻底退出旧版，然后运行 GGYDesk-Setup-1.9.6.exe，选择原安装目录覆盖升级。不要先卸载旧版。保留当前用户与安装范围以正确迁移对应用户的授权。安装中断后不要手动清理 LOCALAPPDATA 下 GGYDESK/upgrade-recovery-1.9.6 的恢复备份，重新运行安装程序。
